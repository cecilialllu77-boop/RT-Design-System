Colors

The color system is composed of primary colors, extended palettes, and semantic alert colors for the Radiotherapy Cloud platform.

1. Primary Palette

Our primary palette consists of dark, white, and green. We use green (#3B9B4D) as the main action color for buttons, labels, and key interactions.

API Reference

PropTypeDefaultDescription
mode"date" | "range" | "month" | "year""date"Whether to pick a date, date range, month, or year.

valuestring—Selected date (YYYY-MM-DD), month (YYYY-MM), or year (YYYY).
disabledbooleanfalseWhether the picker is disabled.
onChange(value: string) => void—Callback when the selected value changes.
